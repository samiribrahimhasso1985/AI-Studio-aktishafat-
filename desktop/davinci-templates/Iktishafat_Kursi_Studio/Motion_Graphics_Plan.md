# Motion_Graphics_Plan — إعادة بناء فيديو المراحل بلقطة C0009
القرار: إعادة بناء **فيديو المراحل كما هو** (إطار هاتف + شريط Raw/CC/Text/Animation/SFX)، والشخصية = لقطة سمير **C0009** بعد إزالة الخلفية الخضراء.
التوقيت: 30fps · المدة 652 إطاراً · الدقة 1080×1920 (الأصل 720×1280؛ كل الأبعاد هنا × 1.5).

- مستطيل 558×996 عند (249, 285)، زوايا نصف قطرها ≈36، ظل ناعم (Blur 30، شفافية 25%).
