## 6. المؤكَّد / المُستنتَج / المجهول
- **مؤكد:** كل التوقيتات والنصوص والألوان المقاسة أعلاه، تكرار اللقطة، بنية المراحل.
- **مستنتج:** نوع الخط (عريض هندسي يشبه Poppins/Montserrat Black)، وأحمر "Hera" ≈ ‎#D8121A‏ تقريباً، ومنحنيات الحركة.
- **مجهول ولن أدّعيه:** الكاميرا، العدسة، الإضاءة الحقيقية، ملفات المشروع الأصلية.
- **ملاحظة:** في زاوية الهاتف السفلى اليمنى علامة ✦ صغيرة ثابتة؛ قد تكون علامة مائية لأداة توليد بالذكاء الاصطناعي، لكن هذا غير مثبت.
- **الشخصية:** امرأة حقيقية أو مولَّدة؛ لا نملك لقطتها الأصلية بجودة كاملة. الملف المرجعي 720p مضغوط بشدة (293 kb/s)، فلا يصلح كمصدر نهائي.
